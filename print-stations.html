Add a printer

  1. Name this printer below, for example “Sandra — shipping 5XL.”
  2. On that Windows computer, download the helper, extract the ZIP, and double-click Install-Print-Station.cmd.
  3. Choose its DYMO printer and enter the pairing code shown here. Leave the computer awake and the printer connected.

The helper starts with Windows sign-in. DYMO Connect must be installed on the printing computer. If Windows asks whether to run the downloaded helper, check that it came from this Invsto page.

Download Windows helper · DYMO software

Already paired? Run the new installer to update the helper; it keeps your existing station. Twin Turbo printers can use Left or Right for each job. Use Roll settings above to name each roll and save a default.

Two printers on one computer? Create a separate pairing code for the second printer, then run Add-Printer.cmd from the extracted download. Choose the 5XL for shipping PDFs; the Twin Turbo pairing stays in place.

Helper 1.2.0 supports saved 4 × 6 shipping PDFs from Pending Orders and Order History. It installs a verified portable PDF print engine. Both printer helpers start when you sign into Windows.

If DYMO can print but Invsto says disconnected, update the helper on that computer, then open the Diagnose Invsto Printer desktop shortcut if needed. Existing queued labels may print when the connection returns.

If an older saved shipping PDF is incomplete, update the eBay Order Link extension and capture the full label again. Extract these files over its existing folder, reload the extension, then refresh eBay and Invsto. Your existing eBay shipping labels are not purchased again.
