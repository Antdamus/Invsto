Your computers

Add a printing computer

  1. Name the computer below, for example “Florida counter.”
  2. On that Windows computer, download the helper, extract the ZIP, and double-click Install-Print-Station.cmd.
  3. Choose its DYMO printer and enter the pairing code shown here. Leave the computer awake and the printer connected.

The helper starts with Windows sign-in. DYMO Connect must be installed on the printing computer. If Windows asks whether to run the downloaded helper, check that it came from this Invsto page.
